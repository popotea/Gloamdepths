# 微光深淵 Gloamdepths

受 Core Keeper 啟發的原創 2D 地底合作生存遊戲。網頁版,免安裝,支援 1–4 人連線。

## 怎麼玩

直接**雙擊 `index.html`** 用瀏覽器開啟(建議 Chrome / Edge)。

### 與朋友連線
1. 進入遊戲後,點右上角「🔗 開房邀請朋友」拿到 5 碼房號。
2. 把 `index.html` 這整個資料夾傳給朋友(或朋友開同一份檔案)。
3. 朋友在主選單輸入房號按「加入房間」即可。
4. **存檔只存在房主電腦**(瀏覽器 localStorage,每 30 秒自動存);朋友的背包以名字保存,下次用同一個名字加入即可拿回裝備。
5. 連線走 PeerJS(WebRTC P2P),不需要架設伺服器;開房與加入時需要網路。離線時仍可單人遊玩。

### 操作
| 按鍵 | 功能 |
|------|------|
| WASD / 方向鍵 | 移動 |
| 滑鼠左鍵 | 挖牆 / 攻擊(自動選背包中最好的鎬與劍) |
| 滑鼠右鍵 | 使用快捷欄選中的物品(放置 / 吃) |
| 1–8 / 滾輪 | 切換快捷欄 |
| E | 背包與合成 |
| F | 在星核旁灌入光晶 |

### 目標
- 星核能量會持續流失:挖**光晶💠**(發亮的藍色礦脈)回來按 F 餵它,歸零就輸了。
- 每 4 分鐘一波**暗潮**圍攻星核:建牆、蓋光塔防守。
- 打敗小地圖上三個金色標記(神殿)的**石像守衛**,帶回 3 塊星核碎片。
- 放入第 3 塊碎片後撐過**最終暗潮**即通關。

## 檔案結構
```
index.html        入口
style.css         UI 樣式
js/config.js      資料表(地形/物品/配方/敵人/平衡數值)
js/world.js       世界狀態、地圖生成、光照、RLE 壓縮
js/inventory.js   背包與合成
js/entities.js    玩家/敵人/掉落物、戰鬥、挖掘、放置
js/game.js        模擬主邏輯、暗潮、星核、存讀檔
js/net.js         PeerJS 連線(房主權威 + 客戶端預測)
js/render.js      Canvas 渲染(視野裁切 + 逐格光照)
js/ui.js          HUD、背包面板、小地圖、選單
js/main.js        輸入與主迴圈
玩法設計.md       完整玩法設計文件
```

## 效能說明(為什麼網頁版不會卡)
- 地圖用 `Uint8Array`:200×200 格僅約 40KB,記憶體毫無壓力。
- 渲染做**視野裁切**:每幀只畫螢幕內約 1,500 格,不畫整張地圖;全黑格子直接跳過。
- 光照逐格計算但只算視野內、光源先做範圍過濾;小地圖用 `ImageData` 並節流重繪。
- 敵人數量有上限(常態 10–16 隻,暗潮期間依波數增加)。
- 連線每秒 10 次快照、座標取兩位小數,一般家用網路頻寬綽綽有餘。

## 調整平衡
所有數值(星核流失速度、暗潮間隔、敵人強度、配方成本)都集中在 `js/config.js`,改完重新整理頁面即生效。

## 材質包

主選單或「Esc → 設定 → 材質包」可切換「深色科幻遺跡」與「原版素材」。
偏好只儲存在本機的 `gld_texture_pack`,不改存檔、數值或連線資料,切換不需要重新開始遊戲。

科技材質放在 `assets/packs/ruins/`:地形、角色、裝備、資源四張圖集共 64 格。
另有 `infrastructure.png` 與 `interiors.png` 共 32 格,提供各式機器、防禦塔、
照明、家具、寶箱、三種巢穴與三階段作物。輸送帶、裝飾地板及礦車以 Canvas 繪製金屬外觀。
涵蓋玩家、所有戰鬥怪物、商人、主要牆面礦脈、武器護甲、工作台、熔爐、箭塔、光塔、
燈具、常見資源、儲物箱與巢穴。相同系列裝備用色調區分;其他物品、動物、寵物與特效沿用既有素材。
地板、星核維持程序化繪製。玩家另有 `explorer-walk.png` 四方向、每方向四格的行走圖集。

圖集與物品映射集中在 `js/texture-pack.js`,原版 `assets/tiles`、`monsters`、`items` 等素材未覆蓋。
角色圖集另有有效範圍 `PACK_CREATURE_FRAMES`,替換圖集時需同步更新裁切座標。
新素材載入失敗會自動退回原版;支援 localhost 與直接雙擊 HTML。
產圖工具與完整提示詞記錄於 `assets/packs/ruins/production.json`。

瀏覽器冒煙測試:已安裝 Python Playwright 與 Chromium 的環境可執行
`python tests/texture-pack-smoke.py`,測試使用隔離瀏覽器,不讀寫玩家的實際存檔。

## 角色動態

主選單可選科技裝甲探索者,或露瑪、布蘭、諾克絲、艾珀四名角色;選擇會隨存檔與連線保留。
探索者在科技材質下使用四格步伐圖集;其餘角色保留各自的方向素材,共用暫停、殘影與受傷效果。
科技角色依實際行走距離切換步伐,移動時朝向行走方向,待機與攻擊時朝向瞄準方向。
各圖格以同一腳底基準裁切;圖集載入失敗時會退回原本單張角色。
衝刺有短暫殘影(每位玩家最多五個),武器分成近戰揮擊、挖礦與遠程後座,
受傷時短暫亮起並輕微震動。重裝怪物動作較沉,幽影與能量體呈現漂浮動態。
動畫遵守系統「減少動態」偏好;暫停時停止推進步伐、呼吸、受擊與殘影計時。

動畫狀態集中在 `js/animation.js` 的 WeakMap,不寫入實體或存檔,不改碰撞、傷害與連線協定。
`node tests/animation.test.js` 檢查幀率一致性、停止、暫停、受傷、衝刺、傳送與方向切換。
可直接開啟 `tests/animation-preview.html` 查看動態示範,或播放
`assets/packs/ruins/animation-preview.webm`。

## 地圖物件外觀

物件呈現集中於 `js/object-render.js`,科技材質使用接地陰影、能源環與全息掃描線。
採礦機與自動熔爐有燃料時亮青燈,缺燃料亮橘燈;箭塔缺箭亮橘燈,停用則灰燈。
狀態燈只代表供能/彈藥,不表示機器已採到礦或正在攻擊;原有燃料、彈藥、容量條保留。
傳輸帶依方向流動,作物成熟時出現亮點。暫停與系統減少動態偏好會停止這些裝飾動畫。
圖集有效範圍記錄在 `object-frames.json` 與 `PACK_OBJECT_FRAMES`,僅裁切留白,不改原始圖片。
可開啟 `tests/object-preview.html` 比較新物件與供能狀態。
